## Project Overview
This project represents a practical deep dive into spreadsheet architecture, logical data modeling, and performance analytics. Using a multi-variable assessment dataset, I structured a clean, automated tracking framework that converts raw, unorganized inputs into standardized, actionable metrics. 

The core goal of this project was to establish an intuitive visual hierarchy while building a dynamic formula infrastructure that scales effortlessly without manual intervention.

> **Key Milestone:** Successfully engineered a scalable system where adding or updating a single raw metric instantly recalculates the entire performance baseline across multiple dimensions.

---

## Core Technical Skills Demonstrated

### 1. Tabular Architecture & Visual Design
* **Data Dimensioning:** Structured clear dimensional boundaries, establishing records (entities) along rows and attributes (variables) across columns for optimized data ingestion.
* **Visual Hierarchy:** Implemented a high-contrast corporate aesthetic using dark blue headers for structural data definition and subtle color-tinted regions to explicitly isolate computed outputs from raw input domains.
* **Typographic Standardization:** Applied precise alignment standards—left-aligning unique string identifiers (Names) to anchor readability and right-aligning quantitative fields to ensure clean mathematical scanning.

### 2. Analytical & Formula Architecture
* **Mathematical Aggregation (`SUM`):** Engineered multi-column accumulation formulas to consolidate raw performance markers into a centralized absolute metric.
* **Statistical Benchmarking (`AVERAGE`):** Calculated arithmetic means across specific evaluation categories to derive performance baselines and identify trend deviations.
* **Data Normalization:** Built logic to scale disparate variables (standardizing 20-point assets against 100-point assets) onto a uniform scale, rendering the final output into a professional percentage format with explicit decimal point constraints.
* **Dynamic Range Referencing:** Implemented a mix of relative and absolute cell references (`$`) to ensure formula integrity across the entire data matrix, eliminating calculation drift when scaling.
